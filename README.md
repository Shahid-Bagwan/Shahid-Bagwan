# Shahid Bagwan

I build software for reliable content and media operations, with an emphasis on permissions, automation, and human review.

## Working principles

- Make authorization and role boundaries explicit before automating actions.
- Keep humans involved where mistakes are expensive or difficult to reverse.
- Measure real outcomes instead of treating generated output as success.
- Prefer systems that are easy to inspect, redirect, and recover.
